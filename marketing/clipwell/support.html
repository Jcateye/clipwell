Before Contacting Support

Check whether monitoring is paused, whether the current app is listed in ignored apps, and whether the global shortcut conflicts with another Mac utility.

Translation Setup

If translation does not respond, open Settings and verify the OpenAI-compatible base URL, model name, and API key. Chinese text should translate to English; English or other non-Chinese text should translate to Simplified Chinese.

Privacy Reminder

Clipwell handles clipboard data. Do not paste passwords, secrets, private documents, or sensitive screenshots into support messages.

Common Fixes

Restart Clipwell from the menu bar, rebuild the local app bundle after development changes, clear history if storage looks stale, and disable optional auto-paste if macOS permission prompts are blocking your workflow.
